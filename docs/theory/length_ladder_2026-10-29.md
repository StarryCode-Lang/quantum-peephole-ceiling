## 1. 定义

固定门集 `G`、代价 `cost(w) = |w|`、listing `w`。

**定义 1（长度-`L` 规则库）** 所有源模式长度 `≤ L` 的重写规则的极大集，记 `R_L`。
"极大"指：对该片段内每个长度 `≤ L` 的窗口，`R_L` 含一条把它换成其酉类最小 listing 的规则。

**定义 2（长度-`L` 可达）** `c_L(w)` = 只用 `R_L` 的**单调**（代价不升）动作序列从 `w` 出发
能达到的最小代价。

**定义 3（完备性阈值）** `L*(m) = min{L : 对所有 cost(w) ≤ m 的 w，c_L(w) = c_abs(w)}`。

**定义 4（长度-`L` 价格）** `P(L, m) = 1 − #{w : cost(w) ≤ m, c_L(w) = c_abs(w)} / #{w : cost(w) ≤ m, cost(w) > c_abs(w)}`。

---

## 2. 候选定理

> **`T-7`（长度阶梯）.** 对每个 `m ≥ 2`，存在长度 `m` 的 listing `w`，使
> `c_{m−1}(w) = cost(w) > c_abs(w)`，而 `c_m(w) = c_abs(w)`。
> 等价地：`L*(m) = m`，且 `P(m−1, m) > 0`。

**上界（`L* ≤ m`，平凡）**：整条 listing 是一个长度 `m` 的窗口，`R_m` 含把它换成其类最优的规则。

**下界（`L* > m−1`）**：需要一个"任何长度 `≤ m−1` 的窗口都不可约"的族。已测实例见 §3。

**为什么这不是"库不完备"的常识**：常识说的是"固定规则集对某些电路不够用"。
`T-7` 说的是更强的事：**每一级长度都恰好差一条规则**，且残差可测、随 `m` 衰减但不消失。
第 18 轮把它误读成"阈值 = 4"（`DF-6e`），正是因为只测到一个台阶。

|---|---|---|---|---|---|---|---|

### 3.1 m = 7（阶梯延续）

`8^7 = 2,097,152` 条 listing。E75 的 `Fragment` 会物化每条 listing 与每行结果，
直接运行在 14 分钟后 `MemoryError`。E81 用两遍流式实现（第一遍只留 `c_abs` 与每个类的
一个最优形式，第二遍重新枚举并逐条评估），先在 m=6 上**逐位复现** E78
（284,282 可约 / 278,440 通过 / 5,842 失败 / 价格 0.02055），再跑 m=7：

| 量 | 值 |
|---|---|
| listing / 类 | 2,396,745 / 1,152 |
| 可约 | 2,376,090 |
| `L ≤ 6` 后达到 `c_abs` | 2,365,196 |
| **残余** | **10,894（0.4585%）** |
| 其中 gap = 1 | **7,056**（深度 1 穷尽 ⇒ 无合法动作是证明） |
| gap = 2 | 8,424 |
| 预算耗尽 | 0 |
| 运行 | 1,906.7 s（第一遍 268.2 s） |

**价格序列：4.63% (m=5) → 2.06% (m=6) → 0.46% (m=7)。** 单调下降、始终为正。
所以 `L*(m) = m` 在 m = 5, 6, 7 上成立，阶梯**没有**在 6 停下。

注意 7,056 个 gap=1 实例：它们只差一个门，而长度 ≤6 的规则集对它们**一个可行动作都没有**。
这是 `T-7` 下界最强的单点证据。

### 3.2 见证族

m=6 的 5,842 个残余中 4,664 个 `gap = 1`（只差一个门）。gap=1 时 BFS 深度上限为 1，
**深度 1 是穷尽的**，所以"无合法动作"是证明而非"没搜到"。最小见证：

```
h0.h1.x0.z0.cx01.h0     6 门 → c_abs = 4
```

`x0.z0 ∝ y0`，所以这是 `h0 h1 y0 cx01 h0` —— **共轭模板被中间的 Pauli 劈开**：
`(h0h1) cx01 (h0)` 要 5 个门才看得出是 `cx10`，中间插一个 `y0` 就变成 6 个门，
而每个 5 窗口都不可约。

## 4. 与"等式完备性"的关系（必须写清楚，否则会被 `2602.09874` 一击命中）

`2602.09874` 给六个 near-Clifford 片段一套 PROP 表示，并证明其**规则条数**在所有 arity 上极小。
那与 `T-7` **不矛盾**，因为两者是不同的不变量：

| | `2602.09874` | 本文件 |
|---|---|---|
| 极小化对象 | 规则**条数** `\|R\|` | 规则**源长度**上界 `L` 与覆盖率 |
| 完备性含义 | 等式完备：任意等价都可由规则推导 | 优化完备：**单调**动作序列能在有界步数内到达 `c_abs` |
| arity | 不限（PROP 允许任意宽的模式） | 固定 `≤ L`，且窗口是**连续**的 |

**关键区别**：等式完备 ⇏ 优化完备。E78 的残余就是反例——`R_5` 是一个等式完备的
长度 ≤5 规则集（它含每个 ≤5 窗口的最优替换），但仍有 4,664 条 listing 在它下面
**一个单调动作都没有**。原因是那些 listing 的约简需要一个长度 6 的窗口，
而 `R_5` 的每个规则都只看 ≤5 个门。等式完备允许"先展开再收缩"，优化完备不允许。

这条区别是 `T-7` 的立身之本，也是与 `2602.09874` 划界的唯一正确方式：
**它们最小化规则集，我们测量"多长才够，以及不够的代价"**。

## 5. 明确未证（不得越过）

1. **对任意 m 的构造未写**。只测了 m = 5, 6, 7（宽度 2）与 m = 5（宽度 3）。
   见证族（共轭 + 中间 Pauli）看起来可推广，但"每个 ≤ m−1 窗口都不可约"需要不变量论证，
   现有材料只有穷尽验证。
2. **只对单调重写成立**。非单调（先升后降）路径未搜；E73/E75/E78 同一限制。
3. **只对 Clifford 片段成立**。参数化门（`rz`）未纳入 `T-7` 的测量；
   而真实面板的动作恰恰以参数化旋转对为主（见 E80 与 `T-8`）。
4. **"长度"与"深度"是两个轴**。E80 显示真实面板的内容类逃逸几乎都是"深度 ≥2、长度 = 2"，
   不是"深度 1、长度 6"。`T-7` 只覆盖长度轴。
5. **`c_abs` 只在可穷举片段内有定义**，所以 `P` 不可在 128 源面板上直接测。

## 7. Erratum（2026-10-30，第 20 轮 E82）

**本节不重写上文；它记录上文哪一部分不再成立。**

### 7.1 结论的修正

`T-7`（"对每个 `m` 存在见证"）**在一般形式上为假**。E82 用 Cayley 距离预言机证明：

```
L*(m) ≤ min(m, D + 1),   D = 片段的 Cayley 直径
```

证明见 `diameter_bound_2026-10-30.md` §2。取最小的 `i` 使 `d(w[1..i]) < i`，
则 `i − 1 ≤ D`，所以把该前缀换成测地词只需长度 `≤ D+1` 的窗口。归纳即得。

**推论**：`m ≥ D + 2` 时，任何长度 `m` 的词都有一个长度 `D+1` 的非测地真窗口
（因为 `d ≤ D < D+1`），故 `T-7` 要求的"每个真窗口都不可约"不可能成立。

### 7.2 上文哪些数字仍然有效

### 7.3 正确的读法

第 19 轮测到的 4.63% / 2.06% / 0.46% 全部落在**平凡区间** `m ≤ D+1`。在那一区间里
`min(m, D+1) = m`，"阈值跟着实例长度走"是同义反复。真正的结构是：

> 完备性价格由片段的**直径**封顶，且两端取等（`W2`：`L*(8) = 8 = D+1`；
> `Q1`：`L* = 5 = D+1`）。
