## 1. 定义

固定门集 `G`、门数 `cost(w) = |w|`、规则库 `L`。把 `L` 的作用分成两类：

- **序类（order）**：保代价的交换动作，只改变门的**位置**，不改变门的**多重集**。
- **内容类（content）**：模式重写，改变门的**多重集**（把若干门替换成不同种类的门）。

记 `E` 为交换动作集，`P` 为模式重写集，`L = E ∪ P`。

**定义 1（可曝光对）** 若 `w[i]`、`w[j]` 是同一线上的可消去对，且中间每个门与两端都独立，
则称该对**可曝光**，穿越距离 `D = j - i - 1`。

**定义 2（交换饱和）** 若 `w` 中不存在可曝光对，称 `w` 交换饱和。

**定义 3（局部 L₀-刚性）** 若 `w` 的每个长度 `≤ L₀` 的连续窗口都**不**等价于更短的 listing，
称 `w` 是局部 `L₀`-刚性的。

**定义 4（完备性价格）** `P(L₀) = 1 - (#{w : c_L(w) = c_abs(w)}) / (#{w : cost(w) > c_abs(w)})`，
其中 `L` 取"长度 `≤ L₀` 的全部模式"这一极大规则集，`c_abs` 为片段内可穷举的绝对最优。

## 2. 定理 5（判定边界）

> **定理 5.** 设 `w` 为 listing。
> **(i)（序类可判定）** `w` 含可曝光对 ⟺ 存在一条长度 `D+1` 的交换序列使该对相邻；
> 判定为 `O(m·w)`，零搜索，且最小所需视野**恰为** `D+1`。
> **(ii)（序类耗尽）** 若 `w` 交换饱和，则**任意长度**的交换序列都不能暴露新的可消去对。
> 因此交换饱和之后的每一点剩余收益都只能来自 `P`，与搜索预算无关。
> **(iii)（边界的含义）** 由 (i)(ii)，"一次约简在某视野内可见吗"在序类内**完全可判定**；
> 序类之外该问题退化为"库里有匹配的模式吗"，即**不是搜索问题**。

**证明** (i) 充分性：中间每个门与两端独立 ⇒ 可逐门冒泡，`D` 次交换后相邻，第 `D+1` 步消去。
必要性：若某个中间门与端点共享线，则冒泡会改变该线的门序，而线序是 trace monoid 的序不变量
（定理 1 的必要性方向）。深度精确性：`D` 次交换是下界，故 `D+1` 最小。
(ii) 即定理 4（不动点证书）：交换饱和 ⇒ 可曝光集为空 ⇒ 任意长交换序列的闭包内仍为空。
(iii) 是 (i)(ii) 的重述。

**经验支撑（E72，冻结面板，零搜索）**

| 量 | 值 |
|---|---|
| 窗口 × 视野行 | 76,236 |
| TP / **FP** / FN / TN | 38,008 / **0** / 1,564 / 36,664 |
| 首次逃逸深度逐窗相等 | 38,006 / 38,008 = 99.995% |
| 覆盖率（raw 根 / greedy 不动点） | 0.9701 / **0.3277** |

**0 假阳性是本定理的充分性方向在 38,008 个独立实例上的无反例检验**；覆盖率的分层差
（97.0% vs 32.8%）是 (iii) 的量化：在真不动点上，67.2% 的逃逸落在边界之外。

## 3. 定理 6（完备性价格的下界）

> **定理 6.** 设规则库 `L` 的所有源模式长度 `≤ L₀`。若 `w` 局部 `L₀`-刚性且 `cost(w) > L₀`，
> 则 `w` 在 `L` 下**合法动作数为 0**，故 `c_L(w) = cost(w)`。
> 于是 `P(L₀) ≥ ρ(L₀)`，其中 `ρ(L₀)` 是"局部 `L₀`-刚性且可约"的 listing 占比。

**证明** 任一动作匹配一个长度 `≤ L₀` 的连续窗口（模式规则）或一对可消去门（`E`，需先曝光，
而曝光要求存在可曝光对，与刚性矛盾）。刚性定义排除了前者的全部匹配。∎

**推论 6.1（阈值而非斜率）** 价格 `P(L₀)` 不是随 `L₀` 平滑下降的，而是存在一个阈值 `L*`：
`L₀ < L*` 时 `P` 随实例长度**上升**，`L₀ ≥ L*` 时 `P = 0`。

**E75 的实测（两个片段，绝对最优可穷举）**

片段 A：2 比特 Clifford，`{h,x,z,cx}`，listing 长度 ≤4，4,681 条 / 458 类 / 2,830 可约。

| 增补的规则类 | 价格 | Δ |
|---|---|---|
| 原库（1,474 条 Quartz） | **30.25%** | — |
| + 全部长度 2（任意 arity） | 30.25% | **0.00** |
| + 单比特长度 3 | 21.20% | −9.05 |
| + 单比特 ≤4 | 20.78% | −9.47 |
| + 双比特长度 3 | 18.16% | −12.09 |
| + 双比特 ≤4 | 2.12% | −28.13 |
| + 全部 ≤3 | **9.12%** | −21.13 |
| + 全部 ≤4 | 0.00% | −30.25（平凡：`L₀ = m`） |

片段 B：1 比特 Clifford，`{h,x,z}`，listing 长度 ≤8，9,841 条 / **8 类** / 9,825 可约。

| 增补的规则类 | 价格 |
|---|---|
| 原库 | 59.25% |
| + 全部长度 2 | **59.25%（Δ = 0）** |
| + 全部 ≤3 | 9.53% |
| + 全部 ≤4 | **0.00%** |
| + 全部 ≤5 … ≤8 | 0.00%（与 ≤4 完全相同） |

**三条可引用的结论**

1. **长度 2 的规则贡献恰好为零**（两个片段都是 Δ = 0.00）。原因不是巧合：`pair_v1` 已经实现了
   相邻自逆消去，所以"长度 2 类"在库里**早已饱和**。任何以"补短规则"为名的改进，
   只要止步于长度 2，收益**精确为零**。
2. **1 比特 Clifford 的完备性阈值恰为 `L* = 4`**。下界：`h0.x0.z0.h0`（4 门，`c_abs = 2`）
   与 `h0.x0.z0.h0.z0`（5 门，**`c_abs = 1`**）的每个长度 ≤3 窗口都不可约，936 条这样的见证；
   上界：长度 ≤4 的极大规则集在 9,841 条 listing 上**零失败**。注意 `L* = 4 ≪ m = 8`，
   所以这不是"规则和实例一样长"的平凡完备。
3. **两种 regime，没有中间态**。片段 B 按长度分层：`P(2)` 随 `m` **上升**
   （0.286 → 0.296 → 0.416 → 0.491 → 0.562 → 0.626，`m = 3…8`），
   `P(3)` 在 0.02–0.13 之间**饱和不衰减**，`P(4)` 恒为 0。
   即：固定长度库的代价不随实例变长而"逐渐摊薄"，它要么涨，要么归零。

## 4. 与既有结果的关系

- 定理 5 解释了 E47/E50/E52/E56/E69 五个孤立结果：它们都是 (i) 在不同预算、不同族上的表现。
- 定理 6 解释了 E58（98.2% 收益是单比特合并）：库只有 14 条单比特规则，它**只能**做单比特合并；
  也解释了 E73 的 856 个失败中的 114 个"零合法动作"实例。
- **`2607.20170`（Quantum Term Rewrite Systems）**：定理 3/4 必须标注为该框架的实例，
  定理 6 的"固定源长度 ⇒ 不完备"在重写系统文献里是常识性观察，本文件的新意只在
  **可测量性**（`P(L₀)` 的定义 + E75 的两个片段），不在"不完备"本身。

## 5. 明确未证（不得越过）

1. **`L*` 没有通用公式**。只证了 1 比特 Clifford `{h,x,z}` 的 `L* = 4`（枚举验证，非证明）。
   片段 A 无法区分 `L* = 4` 与 `L* = m`，因为它的最大长度就是 4。
2. **宽度 ≥3 完全未测**。若 `L*` 随比特数增长，则"固定长度库必然不完备"会变成强命题；
   若 `L*` 恒定，则完备性是**可以买到的**。这是当前最大的未决问题，也是 E77 的目标。
3. **`rz` 连续参数未覆盖**。两个片段都是纯 Clifford，参数化门（`rz(θ)` 的合并与拆分）
   不在定理 6 的范围内。
4. **greedy 短视与库不完备没有分离**。E75 在 `L₀ ≥ L*` 时价格为 0，说明该片段上
   greedy 不产生额外损失；但这是片段性质，不是一般结论。
5. **"价格"只在"绝对最优可穷举"的片段上有定义**。对 128 源面板，`c_abs` 不可知，
   `P` 不可测——这是为什么 E75 必须造片段而不是直接测面板。
