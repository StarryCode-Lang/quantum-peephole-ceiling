# Theorem Registry

**为什么存在**：2026-10-29（第 19 轮）发现仓库里同时存在**三套互不兼容的定理编号**，
同一个 "Theorem 5" 在不同文档里指三个不同命题。手稿正文写 "Theorem 5"、理论文档也写
"Theorem 5"，审稿人按编号查证会对不上。

**规则**：任何引用都必须用本表的 **ID**，不得只写 "Theorem N"。ID 一经分配不再复用。
新增定理先在此登记，再写入正文。

- `MS-*`：手稿（`docs/manuscript/manuscript.md`）的编号，**只在该文档内有效**。
- `FR-*`：`docs/theory/formal_results.md` —— 定理的**权威来源**。
- `EX-*` / `CL-*` / `RG-*` / `BV-*` / `DF-*`：专题文档，各自独立编号。
- `T-*`：尚未定稿的候选定理。
