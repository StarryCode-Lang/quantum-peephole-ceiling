# 直径界：完备性阈值不可能超过片段直径（2026-10-30）

**状态**：定理 `T-9`，**已证**（三行证明，无需搜索）。同时**否证** `T-7`（长度阶梯无界）。
**上游**：`T-7`（`length_ladder_2026-10-29.md`）、`DF-6e`（`decidability_frontier_2026-10-28.md` §6）。
**证据**：`docs/review/science_boost/2026-10-30_diameter_bound/`（E82）。
**编号**：见 `docs/theory/THEOREM_REGISTRY.md`。

---

## 1. 记号

固定门集 `S`，`G = ⟨S⟩`，`cost(w) = |w|`（片段内门数即代价）。

- `d(g) = min{|w| : w ∈ S*, w = g}`：Cayley 距离（= 该酉类在片段内的绝对最优代价）。
- `D = max_{g∈G} d(g)`：片段的 **Cayley 直径**。
- `R_L`：源模式长度 `≤ L` 的**极大**规则库——对每个长度 `≤ L` 的连续窗口 `u`，
  `R_L` 含一条把 `u` 换成其酉类的测地词 `u*`（`|u*| = d(u)`）的规则。
- `c_L(w)`：只用 `R_L` 的**单调**（代价不升）动作序列从 `w` 出发能达到的最小代价。
- `L*(m) = min{L : ∀w, |w| ≤ m ⇒ c_L(w) = d(w)}`：长度-`m` 实例的**完备性阈值**。
- `P(L, m) = 1 − #{w : |w| ≤ m, c_L(w) = d(w)} / #{w : |w| ≤ m, d(w) < |w|}`：完备性价格。

## 2. 定理

> **`T-9`（直径界）.** 对任意片段，`L*(m) ≤ min(m, D + 1)` 对所有 `m` 成立。
> 因而 `P(L, m) = 0` 对一切 `L ≥ D + 1` 与一切 `m`。

**证明.** `L ≤ m` 平凡：整条 listing 是一个长度 `m` 的窗口。

对 `D + 1`：设 `|w| = m` 且 `d(w) < m`（否则已最优）。令 `i` 为使
`d(w[1..i]) < i` 的**最小**下标。则对一切 `j < i`，`d(w[1..j]) = j`；特别地
`d(w[1..i−1]) = i − 1`。由直径定义 `d(w[1..i−1]) ≤ D`，故

```
i − 1 ≤ D    ⟹    i ≤ D + 1.
```

前缀 `u = w[1..i]` 非测地（`d(u) < i`），所以 `R_{D+1}` 含规则 `u → u*`，
`|u*| = d(u) < i`，代价严格下降。得到同元素、更短的 `w'`。对 `|w|` 归纳：
过程终止于一个所有前缀都测地的词，此时 `cost = d(prefix_m) = d(w) = c_abs`。
全过程只用到长度 `≤ D + 1` 的窗口。∎

**推论 1（价格有界）** `L ≥ D + 1 ⇒ P(L, m) = 0`（对所有 `m`）。
完备性价格是**片段不变量**（其直径），不是库的设计属性。

**推论 2（`T-7` 在 `m ≥ D + 2` 处为假）** `T-7` 要求存在长度 `m` 的词使**每个**
真窗口都不可约（即测地）。但长度 `D + 1` 的窗口满足 `d ≤ D < D + 1`，必非测地，
所以任何 `m ≥ D + 2` 的词都有一个可约的真窗口。∎

**推论 3（阈值的精确形式）** 结合 `L*(m) ≥ m`（当 `m ≤ D+1` 且存在局部刚性词时），
`L*(m) = min(m, D + 1)`，其中 `m = D + 1` 处取等。

## 3. 实测（E82，两套独立算法）

`W2` = 2 比特、8 生成元 `{h,x,z}×2 + {cx01,cx10}`（E78/E81 的片段）。
`Q1` = 1 比特、`{h,s,x,z}`（24 元 Clifford 群，E80-A 的片段）。

| 片段 | 群阶 | 直径 `D` | 距离直方图 | `L*` 上界 |
|---|---|---|---|---|
| `W2` | 1,152 | **7** | 1/8/37/121/291/418/253/23 | 8 |
| `Q1` | 24 | **4** | 1/4/8/9/2 | 5 |

`W2` 的直方图与 E81 的 `class_histogram` **逐位相同**，也与本轮的 qiskit `Clifford`
独立 BFS **逐位相同**（三方一致：E78/E81 的词枚举、本轮 tableau BFS、qiskit）。

### 3.1 局部刚性词的普查

`LR_m` = 长度 `m`、**每个真窗口都测地**的词数。这类词在 `R_{m−1}` 下**一个可行动作都没有**，
所以 `c_{m−1}(w) = |w|` 是**证明**而非"没搜到"。

| `m` | `LR_m` | 其中 `d < m` | 其中 `d = m−1`（gap 1） | `LR_m` 是否 > 0 |
|---|---|---|---|---|
| 2 | 64 | 8 | 0 | ✓ |
| 3 | 392 | 70 | 32 | ✓ |
| 4 | 1,890 | 426 | 244 | ✓ |
| 5 | 6,936 | 2,204 | 1,368 | ✓ |
| 6 | 16,900 | 8,172 | **4,664** | ✓ |
| 7 | 20,824 | 15,480 | **7,056** | ✓ |
| 8 | 4,904 | 4,904 | 224 | ✓ |
| 9 | **0** | 0 | 0 | ✗ |

两列加粗值与 E78（m=6：4,664）和 E81（m=7：7,056）**逐位相同**——这是本轮最硬的交叉验证：
完全不同的算法（Cayley BFS vs. 词枚举 + 单调 BFS）在同一批计数上对齐。

**读法**：`LR_m > 0` 对 `m ≤ 8 = D + 1` 成立，在 `m = 9 = D + 2` 处**归零**。
归零不是巧合：长度 8 的窗口 `d ≤ 7 < 8` 必非测地，所以 `LR_9 = 0` 是**定理**。

### 3.2 上界是紧的

- `W2`：`LR_8 = 4,904 > 0` ⇒ `L*(8) ≥ 8`；由 `T-9` `L*(8) ≤ 8` ⇒ **`L*(8) = 8 = D + 1`**。
- `Q1`：E80-A 实测 `L* = 5`，而 `D + 1 = 5` ⇒ **取等**。

两个片段都在 `m = D + 1` 处达到上界，所以 `T-9` 不是松的。

## 4. 对 `T-7` 的处置

`T-7` 的陈述是"对每个 `m` 存在长度 `m` 的词使 `c_{m−1}(w) > c_abs(w)`"。
它**在 `m ≤ D + 1` 时成立**（E78/E81/E82 三方实测），**在 `m ≥ D + 2` 时为假**（推论 2）。

第 19 轮把它读成"阶梯无界、每级残差可测"，并据此重开主刊门。正确的读法是：

> 阶梯只有 `D + 1` 级，第 `D + 1` 级就是顶。E78/E81 测到的 4.63% / 2.06% / 0.46%
> 全部落在**平凡区间** `m ≤ D + 1`，那里 `min(m, D+1) = m`，阈值"跟着实例长度走"
> 是同义反复，不是结构。

`length_ladder_2026-10-29.md` 保留原文，errata 追加在其 §7。

## 6. 明确未证 / 不适用

1. 只对**单调**重写成立。非单调（先升后降）路径未纳入 `c_L` 的定义。
2. 只对**有限片段**（`G` 有限、`D` 可算）成立。含连续参数（`rz(θ)`）的片段 `G` 无限，
   `D` 无定义——这正是真实面板走**深度轴**而非长度轴的原因（E80-B）。
3. `T-9` 给的是**上界**；下界 `L*(m) ≥ min(m, D+1)` 需要局部刚性词的存在性，
   本文件只在两个片段上实测（`W2`、`Q1`），未给一般构造。
4. 窗口是**连续**的。允许非连续模式（PROP 风格）时 `D` 界的证明不适用。

## 8. Erratum (2026-10-31, round 21)

The statement of `T-9` and its proof are unaffected. What is corrected is the
**parameter** substituted for the two-qubit case.

`W2 = {h0, x0, z0, h1, x1, z1, cx01, cx10}` generates a group of order
**1,152**, not the 2-qubit Clifford group (order **11,520**): `{h, x, z}`
generate the order-8 group `⟨h,x⟩` on one qubit and `z = s^2` cannot manufacture
the missing `s`. So §2's `D = 7` is the diameter of an index-10 **subgroup**.

On the project's own basis `{h, x, rz, cx}` — where `rz` is a single native gate
for every angle, so `z = rz(pi)` and `s = rz(pi/2)` both cost 1, and where both
CX directions are native (the frozen panel contains 18,234 forward and 6,348
reversed CX) — the diameter is **9** and the threshold is **10**, not 8.

Consequences: the shipped library's maximum source length (5) is **5 levels**
short, not 3; and `L*(8) = 8 = D+1` no longer reads as "the bound is attained on
the 2-qubit Clifford group". The one-qubit claim (`Q1`: `D = 4`, `L* = 5`) stands
and is reproduced bit-exactly.

See `panel_diameter_and_length_floor_2026-10-31.md` (`PD-1`, `PD-2`, `LF-1`,
`LF-C1`) and `docs/review/science_boost/2026-10-31_innovation_scan.md`.
