# v15 repository cleanup record — 2026-10-11

**Scope:** repository footprint reduction. **Not touched:** any file pinned by
`release/release_manifest.json`, `release/prepaper_release_manifest.json`,
`release/v13_release_manifest.json` (if present), or the v12-v15 package
receipts; any experiment data; any receipt or verdict.

| Item | Size | Status before removal | Why safe |

| `release/prepaper_restore_capsule.zip` | 84 MB | tracked, **not pinned** by any manifest, not exercised by any test | the capsule snapshots exactly the files pinned by `release/prepaper_capsule_inner_manifest.json`, all of which are recoverable from Git history at their recorded hashes |

Net working-tree reduction: about 540 MB (release/ 201 MB -> 30 MB; the tree
excluding `.git` is now dominated by frozen evidence).

## What was deliberately kept

- All sealed and canonical data packages (`data/v2_fixed`, `v4`-`v15`),
  including the large sealed E31 factorial (`data/v11/e31_factorial_pareto`,
  506 MB) and the v14 certificates with full state-set hashes
  (`data/v14/e45_full_development`, 319 MB): these are the hash-pinned
  evidence chain and are not disposable.
- `analysis/rerun_*`, `analysis/revalidate_*`, and other one-off scripts that
  look obsolete: they are hash-pinned members of the prepaper manifest and are
  imported by tests; deleting them would break the recorded verification
  chain.
- `release/prepaper_*_manifest.json` and the restore-audit receipts: the
  receipts remain the record that the capsules passed a byte-complete restore
  test before retirement; the zips themselves were redundant with Git history.

## Consequences for readers

- The sentence "removed process notes remain available in the frozen restore
  capsule and Git history" is superseded: they remain available in Git
  history.
- `scripts/archive_restore_audit.py` keeps its executable contract (its test
  builds a tiny synthetic capsule); the retired real capsules can be rebuilt
  from the inner manifests plus Git history if a future audit needs them.
