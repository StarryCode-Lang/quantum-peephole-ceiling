## 1 本轮新增证据

### 1.1 E62：旋转度量下的绝对下界、三分解与湮灭墙

脚本 `scripts/e62_rotation_gap.py`，证据包 `docs/review/science_boost/2026-10-25_rotation_gap/`。

**做了什么**：把 128 个源按 Hadamard 切成极大 `{x, rz, cx}` 片段，对每个片段抽取
相位多项式、约化、取支撑 $s$；用引理 1（$R \ge s$）给出每实例可计算的旋转数下界；
再用已验证的交换闭包（定理 1–4）把"到最优的距离"劈成交换可达部分与内容部分。

**全面板（128 源，旋转度量）**

| 量 | 值 |
|---|---|
| $R(\text{root})$ → $R(\text{closure})$ | 35,361 → **30,054**（−5,307，−15.0%） |
| $\Sigma(\text{root})$ → $\Sigma(\text{closure})$ | 30,241 → 28,858 |
| $g_{\text{total}}$（root 口径） | 5,120 |
| $g_{\text{reorder}}$ | 5,307 |
| $g_{\text{content}}$（closure 口径） | 1,196 |
| 湮灭增益 | 1,383 |
| 闭包达自身片段最优 | 97/128 |
| 有 reorder 间隙 / content 间隙 | 63 / 31 |
| 下界违例 | **0 / 0**（root 与 closure 各 128/128 成立） |

恒等式校验：$5{,}120 = 5{,}307 + 1{,}196 - 1{,}383$。✓

**合成阶梯（36 实例，$n=4\ldots32$，片段内）**：$g_{\text{total}}=511$，
$g_{\text{reorder}}=489$（**95.7%**），$g_{\text{content}}=22$（4.3%），18/36 已达绝对最优，
$s$ 不变 36/36。

**三条结论**

1. **参照点问题解决（片段内）**：$s$ 是酉不变量，故 $R \ge s$ 是绝对下界；18/36 实例的
   闭包输出即为达到下界的见证电路（酉相等 12/12，含全局相位，残差 $3.3\times10^{-15}$）。
2. **内容类判据闭合**：$g_{\text{total}} = g_{\text{reorder}} + g_{\text{content}}$（片段内），
   两半均 $O(mw)$ 可算。第 11 轮 P1-1 在旋转度量下完成。
3. **湮灭墙（否定性定理）**：分段界 $\Sigma$ **不是**酉不变量——54/128 个源满足
   $R(Tc) < \Sigma(c)$（VQE −196、HaarRandom −138、Grover −106、UCCSD −80）。
   机制是相邻 $h\,h$ 被消去后两个片段合并，合并后的支撑可严格小于两段之和。
   **因此含 $h$ 的通用电路不存在相位多项式式的绝对判据**，天花板是度量的不连续性，
   不是优化器不够努力。

**被本轮推翻的自己的猜想（两条，均留证）**

- "同线同形式 ⇒ 必然可交换曝光"——**假**。反例 `pp_random_n4_r1`（闭包输出位置 9/17）：
  线 2 的形式 $6 \to 7 \to 6$ 往返，两个 `cx(1,2)` 都与 `rz(2)` 不对易，无任何交换序列可合并。
- "分段界可推广到含 $h$ 电路"——**假**，即湮灭墙。

**必须声明的弱点**：冻结面板的 35 个单段源合计只有 45 个 `rz`，**全部平凡达标**。
冻结面板对片段内结论没有非平凡贡献，定量证据完全来自合成阶梯。这是 P0-1 的首要补齐项。

## 4 创新方向清单（按优先级）

### P0-1 绝对参照点 + 三分解 + 湮灭墙（本轮完成，论文理论核心）

- **与现有工作的本质差异**：文献给"某个门类的精确最优"（`2610.01024` 给 CCZ 层 T-count），
  本项目给的是"**任意局部重写优化器离最优有多远、以及这段距离由什么构成**"——
  一个分解，而不是一个数。并且给出**为什么分解不能跨 Hadamard** 的定理。
- **可行性**：**理论已完成**（`docs/theory/rotation_gap_2026-10-25.md`）；
  实验只完成合成阶梯，冻结面板退化。
- **所需新增证据**：
  1. **片段原生基准**：$n=4\ldots64$、≥6 族（结构化对角族、线性可逆+旋转族、Trotter-ZZ 族、
     IQP 对角核、算术相位段、随机相位多项式），每族 ≥8 实例，$s$ 可解析或可独立计算；
  2. 在该基准上重跑 E62，报告 $g_{\text{reorder}}/g_{\text{total}}$ 随 $n$ 的标度律；
  3. 命题 2 从"充分"升级为"充要"（需要证明不存在第三种机制）；
  4. 定向检索确认三分解未被占位（`2610.01024` 的引用网络是最快的入口）。
- **预期影响力**：**高**。它同时解决了"相对什么"和"为什么不能更好"两个必答问题。
- **投稿层级**：PRX Quantum 理论节核心；若标度律漂亮，可作主刊的"定律"候选。

### P0-2 证书即编译器回归测试（本轮闭环，最快见效）

- **本质差异**：不是新方法，是**新用途**——把不动点证书当作编译器的单调性测试。
  已在 2.4.1 上检出真实缺陷（6/101、+226 门、191 个未合并 `rz` 对），
  并在 2.6.1 上确认修复（0/101、0、0）。
- **可行性**：**已完成**（E61 + E63）。
- **所需新增证据**：
  1. 扩到 3 个基（冻结基 / `{rz,rx,cx}` / `{u,cx}`），确认缺陷的基依赖性（E61 已知默认基无缺陷）；
  2. 把 tket `FullPeepholeOptimise` 与 BQSKit 作为阴性/阳性对照纳入同一测试；
  3. 固化为可复用测试脚本 + 一段 20 行以内的最小复现。
- **预期影响力**：**高**（可复算、可反驳、有工程后果），是"别人会引用"的那一条。
- **投稿层级**：论文一节 + 工具轨短文；不需要单独投稿。

### P0-3 规则库完备化：用 Knuth-Bendix 补全派生缺失规则（本轮新增，下一个最高杠杆）

- **本质差异**：本项目一直把 1,474 条规则当**给定**；`2607.19059` 证明实际规则集可以完备，
  `2610.01246` 证明 KBC 能自动补全。于是"内容类间隙"可以被重新表述为
  "**规则库在什么意义下不完备，补全后间隙缩小多少**"——这是可测量、可证伪的命题。
- **可行性**：**高**。E62 已经给出一个具体的缺失规则类：往返阻塞（机制 B）意味着
  `rz` 无法穿过"净效应为恒等但逐门不对易"的 CNOT 段。这条规则的**存在性**已被反例证明，
  只需把它写成定向规则并验证语义。
- **所需新增证据**：
  1. 把机制 B 的缺失规则写成候选规则（形如 `rz(q) · S · rz(q) → rz(q)+rz(q) · S'`，需给出 $S'$）；
  2. 在 `e44_core_v1` 上做一次 KBC 风格的关键对分析，列出所有可导出但未收录的规则；
  3. 补全后重跑 128 源，报告 $g_{\text{content}}$ 的下降幅度（当前 1,196）。
- **预期影响力**：**中高**。它把"规则库是外部给定"这一最弱的方法论假设变成可检验对象。
- **投稿层级**：PRX Quantum 的必要条件；也是回应 `2607.19059`/`2610.01246` 的唯一硬办法。

### P1-1 跨线合并 → 带约束 token swapping 的归约

- **本质差异**：机制 A（跨线重复单项式）天然就是 token swapping：要把同一单项式的两次
  出现搬到同一条线。`2601.09681`（约束着色 token swapping，PSPACE）与 `2608.03825`
  （CNOT-distance NP-完全）给出两侧的复杂度锚点。
- **可行性**：中（需一次规范归约，且要处理"线数固定、禁止 ancilla"的约束）。
- **所需新增证据**：严格归约 + 至少一个"路径图 vs 一般图"的可解性对照实例。
- **预期影响力**：中高；若成立，是**唯一还开着的主刊理论门**（复杂度二分：序类 poly、内容类 hard）。
