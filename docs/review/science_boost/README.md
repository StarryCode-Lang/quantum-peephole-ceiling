## 当前主线（2026-10-24 起）

**局部重写优化的"终止"是可判定的，判定成本 $O(m\cdot w)$，无需搜索。**

1. **判据**：一对可约门可被交换律带到相邻 ⟺ 中间每个门与两端都独立
   （定理 1，`docs/theory/exposability_criterion_2026-10-23.md`）。
2. **终止与单趟最优**：每趟至少删 2 门 ⇒ 有限趟终止；单趟收益是区间调度最大值，
   按右端点升序可达（定理 2/3）。
3. **不动点证书**：闭包停在空可曝光集 ⇒ **不存在任何长度**的交换序列能再造出可约相邻对
   （定理 4）。引理 3（曝光单调性）给出机制；代价不变性见猜想 1。
   全部见 `docs/theory/closure_termination_and_optimality_2026-10-24.md`。

**三条必须同时记住的否定性结果**：

- 闭包的 −10.44% 里 **98.2% 是单比特门合并**，两比特口径只有 −0.53%。不得再用
  "缓解容错成本"叙事。
- **闭包不比生产编译器强**：Qiskit L3 输出在 95/101 源上已经是闭包不动点。
- tket/BQSKit 的"闭包增益 58%/61%"是**规范化假象**（扩张 5.75×/6.40×），不得引用。

**可应用的那一条**：Qiskit 2.4.1 在基 `{h,x,rz,cx}` 下 `optimization_level=3` 劣于 `=2`
（6/101 源、+226 门、191 个未合并 `rz` 对，E61；报告草稿见
`docs/review/qiskit_l3_monotonicity_issue_2026-10-24.md`）。

**投稿层级**：Quantum 首选；PRX Quantum 需先完成内容类判据；主刊因量级不足关闭。
