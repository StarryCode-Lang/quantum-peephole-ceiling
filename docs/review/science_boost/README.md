## 当前主线（2026-10-23 起）

**「逃逸」分两类，且可分。**

1. **序类（order）**：由交换律单独可达。定理 1 给出精确判据——一对可约门可曝光
   ⟺ 中间每个门与两端都独立；所需视野 $h^*=D+1$，$D=j-i-1$。判定复杂度 $O(m\cdot w)$，
   **无需搜索**（`docs/theory/exposability_criterion_2026-10-23.md`）。
2. **内容类（content）**：无任何可曝光配对，必须由库中改写规则改变门的内容。
   BV $n\le24$ 在 $D\le512$ 内穷尽为零 → 内容类是证明级的（E56）。

**闭包推翻了"认证景观"的语义**：h=3 是"≤3 个动作"，不是最优性。
128 源上闭包（零搜索、128/128 证书重放）把 70,293 门降到 62,952（−10.44%），
而 76,236 次认证搜索只降 0.21%；闭包在 60/128 源上严格优于冻结 `best_cost`。
外部对照 tket 2.18.0 `RemoveRedundancies`：闭包 12,192 vs tket 12,691（123 源，基线 17,999）。

因此：**`best_cost` 必须改称 `best_cost_at_h3`**；论文的对象从"认证景观"换成
"闭包不动点 + 内容类残差"。PRX Quantum 仍为现实首选，且现在缺的只是定理书写与 2q 口径。
