## 当前主线（2026-10-26 起；10-28 增补；11-04 改判为两轴）

**逃逸集合按"第一步是否降代价"划分成内容优先与序优先两类；两类与两个根分层重合，
一轴可判定、一轴可计数。**

0. **划分**（`AX-1`，定义展开，不是定理）：每次逃逸的第一步要么 `cost_delta < 0`
   （内容优先），要么 `= 0`（序优先）。E90 在 38,118 个冻结窗口上量出
   **19,303 / 699**（96.5% / 3.5%），且 **19,303 个全部落在 RAW 层**，
   greedy 层的 1,228 个窗口**零个**内容优先。⇒ **内容轴是未优化基线的产物，
   序轴是 greedy 不动点的全部机制。**
1. **判据**：可约对可被交换律带到相邻 ⟺ 中间每个门与两端都独立；所需视野 `h* = D+1`，
   D = 中间的间隔（定理 1）。→ h 是推论，D 才是自变量。
2. **终止与不动点证书**：定理 2/3/4（`closure_termination_and_optimality_2026-10-24.md`）。

   **E69（宽度效应 +11.8pp ≈ 6 × 视野效应 +2.0pp，且四组对比零反转）**。
