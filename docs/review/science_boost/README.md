## 当前主线（2026-10-24 起）

**局部重写优化的"终止"是可判定的，而且判定成本是 $O(m\cdot w)$、无需搜索。**

1. **判据**：一对可约门可被交换律带到相邻 ⟺ 中间每个门与两端都独立（定理 1，
   `docs/theory/exposability_criterion_2026-10-23.md`）。
2. **终止与最优**：闭包每趟至少删 2 门 ⇒ 有限趟终止；单趟收益是区间调度最大值，
   按右端点升序可达（定理 2/3）。现行实现按 $D$ 升序，**没有**最优性证明。
3. **不动点证书**：闭包停在空可曝光集 ⇒ **不存在任何长度**的交换序列能再造出可约相邻对
   （定理 4）。这是九轮以来第一个与搜索预算无关的否定性结论。
   （定理 2/3/4 见 `docs/theory/closure_termination_and_optimality_2026-10-24.md`。）

**必须同时记住的三条否定性结果（第 11 轮）**：

- 闭包的 −10.44% 里 **98.2% 是单比特门合并**，两比特口径只有 −0.53%。
  **不得**再用"闭包缓解容错成本"叙事。
- **闭包不比生产编译器强**：qiskit L3 输出在 95/101 源上已经是闭包不动点。
- tket/BQSKit 的"闭包增益 58%/61%"是**规范化假象**（扩张 5.75×/6.40×），不得引用。

**可应用的那一条**：qiskit 2.4.1 在基 $\{h,x,rz,cx\}$ 下 `optimization_level=3` 劣于 `=2`
（6/101 源、+226 门、191 个未合并 `rz` 对、闭包再删 207 门且 6/6 幺正等价，E61）。
这是把证书当**编译器回归测试**用的第一个成功案例。

因此：`best_cost` 仍须改称 `best_cost_at_h3`；论文对象是"闭包不动点 + 内容类残差"；
投稿首选由 PRX Quantum **下调为 Quantum**，PRX Quantum 需先完成内容类判据。
