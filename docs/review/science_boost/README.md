## 当前主线（2026-10-25 起）

**局部重写优化的"最优"只在相位多项式片段内可绝对定义；跨出片段的障碍是一条定理。**

1. **判据**：一对可约门可被交换律带到相邻 ⟺ 中间每个门与两端都独立
   （定理 1，`docs/theory/exposability_criterion_2026-10-23.md`）。
2. **终止与单趟最优**：定理 2/3；**不动点证书**：定理 4
   （`docs/theory/closure_termination_and_optimality_2026-10-24.md`）。
3. **绝对参照点**：片段内 $R \ge |\mathrm{supp}(f)|$（引理 1，文献结论 + 新用途）；
   间隙可劈成 reorder / content 两半（命题 1/2）；合成阶梯上 reorder 占 **95.7%**。
4. **湮灭墙**：分段界不是酉不变量——54/128 个源在闭包后低于 root 的分段界，
   机制是相邻 `h h` 被消去导致片段合并。**含 $h$ 的通用电路不存在相位多项式式的绝对判据。**
   全部见 `docs/theory/rotation_gap_2026-10-25.md`。

**四条必须同时记住的否定性结果**：

- 闭包的 −10.44% 里 **98.2% 是单比特门合并**，两比特口径只有 −0.53%。
- **闭包不比生产编译器强**：Qiskit L3 输出在 95/101 源上已经是闭包不动点。
- tket/BQSKit 的"闭包增益 58%/61%"是**规范化假象**（扩张 5.75×/6.40×），不得引用。
- "同线同形式 ⇒ 可曝光"**是错的**（往返阻塞反例）；"分段界可推广到含 $h$"**也是错的**。

**可应用的那一条（已闭环）**：Qiskit 2.4.1 在基 `{h,x,rz,cx}` 下 `optimization_level=3`
劣于 `=2`（6/101 源、+226 门、191 个未合并 `rz` 对）；**Qiskit 2.6.1 上该缺陷已消失**
（0/101、0、0，E63）。证书由此获得一个已闭环的用例：编译器回归测试。

**投稿层级**：Quantum 首选（证据已齐）；PRX Quantum 需先补片段原生基准；
主刊仍关闭（量级 + 硬件 + 复杂度分离三者皆缺，P1-1 是唯一还开着的门）。
